## Settings that decide whether it can be found

- **Visibility: Public.** Unlisted videos never appear in YouTube or Google search, whatever the title says. The link stays the same when you switch.
- Category: Science & Technology. Language: English (or Arabic for the Arabic video). Captions: YouTube's auto-captions add searchable words; check them once.
- Thumbnail: the title card or the "One Riaya, every screen" image (`docs/shots/00-every-device.png`) reads better than an auto frame.
- Add both videos to one playlist named "Riaya – Future Health Challenge 2026", and pin a comment with the live link.
- Put the video link in the README (done) and anywhere you post about the project (LinkedIn), so outside links point at it.
